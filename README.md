# PGK Champs — контент от сообщества

Каталог материалов, которые студенты добавили сами: видео и источники по
темам глав, пресеты тренажёров, ссылки на свои репозитории и полезные
инструменты. Платформа читает
`community.json` напрямую и показывает каталог на странице
[/community](https://pgk-champs.github.io/platform/community).

## Как добавить своё

1. Возьмите у наставника секретный код.
2. Откройте [форму заявки](https://github.com/pgk-champs/leaderboard/issues/new?template=submit-content.yml)
   в репозитории лидерборда (нужен тот же доступ, что и для лидерборда).
3. Заполните поля и отправьте. Бот проверит код и данные — при успехе
   материал появится в `community.json` в течение минуты.
4. Ошиблись или хотите обновить материал? Отправьте заявку ещё раз —
   новая версия добавится в каталог.

В этот репозиторий не коммитят руками — только бот из проверенных заявок.

## Схема community.json

Массив записей:

```json
{
  "id": "i42",
  "type": "preset",
  "title": "Словарь недели 3",
  "author": "student-login",
  "chapterId": "it-english",
  "data": { "name": "Словарь недели 3", "engine": "flashcards", "cards": [{ "term": "branch", "translation": "ветка" }] },
  "addedAt": "2026-09-01T12:00:00.000Z"
}
```

- `id` — `i<номер issue>`, уникален для каждой принятой заявки.
- `type` — `preset` | `repo` | `link` | `video` | `source`.
- `title` — заголовок карточки в каталоге.
- `author` — GitHub-логин автора (берётся из issue, подделать нельзя).
- `chapterId` — необязательная привязка к главе платформы: короткий id главы
  (буквы латиницы в нижнем регистре, цифры, дефис — `^[a-z0-9-]+$`), без
  раздела и номера, например `it-english`, а не `foundation/02-it-english`.
- `data`:
  - для `preset` — данные движка платформы (`engine`:
    `flashcards` | `wordorder` | `codetyping` | `predict` и поля движка,
    как в конструкторе /gym);
  - для `repo`, `link`, `video` и `source` — строка с `https://`-адресом
    (`video` — обязательно ссылка на youtube.com или youtu.be).
- `addedAt` — ISO-время принятия.

## Правила

- Только данные для движков платформы и ссылки — никакого исполняемого кода.
- Ссылки — только `https://`.
- Материалы без кода наставника не принимаются.
